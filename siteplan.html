DevLaunch Portfolio Site Plan

Site Name

DevLaunch Portfolio

This name was selected because the website will showcase my software and web development projects while helping launch my professional career.

Site Purpose

The purpose of this website is to present my skills, projects, education, and contact information as a software and web development student. The site will help recruiters and companies learn more about my abilities and contact me for internships or employment opportunities.

Scenarios

  • What programming languages and technologies does the developer know?
  • How can I contact the developer regarding an internship opportunity?
  • What projects has the developer completed?
  • Can I download the developer's resume?

Color Scheme

```

#F8FAFC (Light Gray) - Used for page backgrounds and content sections.

#F59E0B (Orange) - Used for accents, buttons, and highlights.
```
